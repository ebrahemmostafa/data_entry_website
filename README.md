# خطواتي — متابعة المشي اليومية

صفحة ثابتة باللغة العربية لتسجيل مدة المشي اليومية ومراجعة السجل وملاحظة التحسن.

تستخدم الصفحة Supabase Auth وPostgres لحفظ البيانات أونلاين. كل حساب يرى تسجيلاته فقط، ويمكن فتح السجل من أي جهاز بعد تسجيل الدخول بنفس الحساب.

## التشغيل

افتح `index.html` عبر خادم تطوير بسيط أو استخدم رابط GitHub Pages. يحتاج تسجيل الدخول إلى اتصال بالإنترنت. النسخة المنشورة متصلة بمشروع Supabase وتستخدم مفتاحًا publishable آمنًا للواجهة مع سياسات RLS على الجداول.

## النشر

المشروع مناسب للنشر على GitHub Pages من فرع `main` أو `master` باستخدام مجلد الجذر. مخطط قاعدة البيانات محفوظ في `supabase/migrations/20260809000000_walking_tracker.sql`.
