# خطواتي — متابعة المشي اليومية

صفحة ثابتة باللغة العربية لتسجيل مدة المشي اليومية ومراجعة السجل وملاحظة التحسن.

## التشغيل

افتح `index.html` مباشرة في المتصفح. البيانات تُحفظ محليًا في المتصفح باستخدام `localStorage`، ولا يتم إرسالها إلى أي خادم.

## النشر

المشروع مناسب للنشر على GitHub Pages من فرع `main` أو `master` باستخدام مجلد الجذر.
