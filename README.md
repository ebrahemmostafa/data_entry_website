# خطواتي — متابعة المشي اليومية

صفحة ثابتة باللغة العربية لتسجيل مدة المشي اليومية ومراجعة السجل وملاحظة التحسن.

تستخدم الصفحة Supabase Postgres لحفظ سجل واحد مشترك أونلاين. لا تحتاج الصفحة إلى تسجيل دخول، لذلك يمكن فتح نفس السجل من أي جهاز مباشرة.

تنبيه: لأن الدخول مفتوح، أي شخص معه رابط الموقع يستطيع قراءة وتعديل السجل المشترك.

## التشغيل

افتح `index.html` عبر خادم تطوير بسيط أو استخدم رابط GitHub Pages. يحتاج الحفظ إلى اتصال بالإنترنت. النسخة المنشورة متصلة بمشروع Supabase وتستخدم مفتاحًا publishable للواجهة مع سياسات RLS تسمح بالسجل المشترك فقط.

## النشر

المشروع مناسب للنشر على GitHub Pages من فرع `main` أو `master` باستخدام مجلد الجذر. مخطط قاعدة البيانات محفوظ في `supabase/migrations/20260809000000_walking_tracker.sql` و`supabase/migrations/20260809001000_shared_walking_tracker.sql`.
